# Hola Mundo Web

Una aplicación web moderna y elegante que muestra un "Hola Mundo" interactivo.

## Características

- **Diseño Moderno:** Creado con Tailwind CSS, con un aspecto visual de *Glassmorphism* y gradientes atractivos.
- **Interactividad:** Permite personalizar el saludo ingresando tu propio nombre.
- **Multilingüe:** Cambia instantáneamente el saludo entre Español, Inglés y Francés.
- **Reactivo:** Desarrollado utilizando Alpine.js para una experiencia de usuario fluida y sin recargas.

## Uso

Simplemente abre el archivo `index.html` en cualquier navegador web moderno para probarlo.
